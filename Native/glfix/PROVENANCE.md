# Provenance

The local interposer, pbuffer emulation, Command-key filter and native regression
tests were ported from the project's existing compatibility experiments. Original
runtime fixes are retained; internal experiment references, machine-specific paths
and diagnostic-only probes have been removed. Local files are published under MIT
by the project maintainers. No Wine or Apple framework implementation is vendored.
Apple framework headers and runtime libraries are supplied by the system SDK.
