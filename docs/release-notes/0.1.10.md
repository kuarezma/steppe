### Fixed
- **Preserve custom resolution (`AppSettings.resolution(for:modes:)`)**:
  - Custom resolutions (such as `1600×900` on a notched built-in MacBook display) are now written directly to `profile.cfg` without being snapped to Windows `DisplayModes`.
  - Ensures user-configured custom resolutions are strictly respected and not overridden during launch planning.
- **Skip redundant display-mode probe before launch (`SteppeController.runPlay`)**:
  - `list-modes.exe` is no longer spawned before launching `cossacks.exe` when custom resolution is enabled.
  - Cached `displayModes` are reused across launches unless the macOS display topology changes (`handleDisplayChange`), accelerating game startup.
- **Startup environment diagnostics**:
  - Logs the selected Windows user folder, directories under `drive_c/users`, and `cossacks.ini` `UseMultithreadedMode` setting on launch to aid troubleshooting and prefix diagnostics.

### Düzeltilenler (Türkçe)
- **Özel Çözünürlüğü Koruma (`AppSettings.resolution(for:modes:)`)**:
  - Özel çözünürlükler (örneğin çentikli yerleşik MacBook ekranında `1600×900`), Windows `DisplayModes` listesine zorla uydurulmadan (snap edilmeden) doğrudan `profile.cfg` dosyasına yazılır.
  - Özel çözünürlük aktifken kullanıcının belirlediği boyutlar kesin olarak korunur ve başlatma planlayıcısı tarafından ezilmez.
- **Başlatma Öncesi Gereksiz Ekran Modu Taramasını Atlama (`SteppeController.runPlay`)**:
  - Özel çözünürlük etkinleştirildiğinde `cossacks.exe` başlatılmadan önce `list-modes.exe` süreci gereksiz yere çalıştırılmaz.
  - Önbelleğe alınan `displayModes` bilgisi, macOS ekran topolojisi değişmediği sürece (`handleDisplayChange`) sonraki açılışlarda tekrar kullanılarak oyunun başlama süresi hızlandırılır.
- **Başlangıç Ortamı Tanılamaları**:
  - Sorun giderme ve Wine prefix analizini kolaylaştırmak için seçilen Windows kullanıcı klasörü, `drive_c/users` altındaki mevcut dizinler ve `cossacks.ini` içindeki `UseMultithreadedMode` ayarı başlangıçta loglara kaydedilir.
