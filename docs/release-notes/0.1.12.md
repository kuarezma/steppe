### Fixed & Hardened
- **Process, download & logging resilience (`ProcessKit`, `Downloader`, `Logger`)**:
  - Redacted `stderr` prior to truncation, protected pipe draining and process state with locks so cancelled tasks throw `CancellationError`, synchronized `DownloadDelegate` with `NSLock`, guarded non-positive `expectedContentLength`, and added `Log.shared.detachAndFlush()` before uninstall.
- **Launch lifecycle, Steam & prefix safety (`SteppeController`, `GameFiles`, `SteamKit`, `WinePatcher`, `ProfileTuner`, `WineEnvironment`, `Diagnostics`, `GameProfile`)**:
  - Added rapid non-start detection (`SetupError.gameDidNotStart`), `.steamClosedReopen` feedback when Steam exits after sign-in, resilient `forceStop()`/`attachToRunningGame()` state recovery, bounded `frames.ns.<pid>` pruning (5 files / 20 MB), accurate download-speed resets, and pre-repair disk-space checks (`16 GB` / `11 GB`).
  - Extended hash-guarded restores to audio DLLs (`ogg.dll`, `vorbis.dll`, `vorbisfile.dll`), cleared `patchLogFile` on restore, blocked `appmanifest` `installdir` path traversal, enforced `codesign --verify --strict` for audio entitlements, inserted missing `UseMultithreadedMode` inside the `Engine` block preserving LF/CRLF, switched helper tools to `WineEnvironment.tool()`, and moved `Diagnostics.export` off the main actor.
- **Native shims (`glfix`, `vorbis-fast`, `dialog-helper`)**:
  - Added share-group-aware mutex-protected bone-location caching, `GL_PACK_ALIGNMENT`/`GL_READ_BUFFER` save/restore, cross-sharegroup FBO protection, dynamic multi-match `patch_bush_shader`, and MRC `dispatch_release` in `cmdfilter.m`.
  - Added case-insensitive `ambient` bypass, single-stream checks, bounded `OV_HOLE` retries, full `channels * word` frame alignment, and zero-length SSE guards in `vorbisfile_fast.c`, plus `GetClientRect` validation in `dismiss_dialog.c`.

### Improvements & Tests
- **UI, localization, CLI, scripts & docs (`Steppe`, `steppe-cli`, `Scripts`, `docs`)**:
  - Disabled *Check for Updates…* while busy, removed duplicate folder-picker refresh calls, added missing-folder toasts and zero/singular/plural restore messages (EN/TR), filtered `resolutionChoices` by height, added per-command CLI flag checks, fixed non-overlapping prerelease offsets in `Scripts/build-app.sh` and exact filename matching in `Scripts/install.sh`, and expanded Swift/native test coverage (104 XCTest cases).
