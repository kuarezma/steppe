Fixes the crash at `00427A2B` (“Write of address 00000000”) when playing on an external display ([#1](https://github.com/kuarezma/steppe/issues/1)):

- Steppe planned the game's resolution for the screen its own window was on, which could be a size the Windows environment cannot list as a display mode. The game then crashed on startup.
- Before each launch Steppe now asks Windows inside the game environment for its display modes, plans the resolution for the monitor the game runs on and writes only a listed mode. Custom resolutions are checked the same way.
- *Settings → Choose the resolution myself* offers the display modes Windows reported once you have played once. The log and *Export Diagnostics* show the monitor and the resolution written.

Existing installs update automatically.
