Easier in-app update controls:

- **Updates menu in Settings**: shows the installed version and last check time, a one-click **Check for Updates…** button, toggles for **Check for updates automatically** and **Download and install updates automatically**, and a direct link to the release notes.
- **Top-bar update & settings buttons**: both the Welcome screen and the Ready screen now include a quick **Check for Updates…** button right next to the Settings gear icon.

Existing installs update automatically.
